DAYBLOOM | ADVENTURER'S JOURNAL
A personal, free, Genshin-inspired planner. No subscription or account.

QUICK TEST
Open the separate Daybloom_Teyvat_Standalone.html file in a browser. It contains all artwork and code. Saving data from a local HTML file varies by browser.

INSTALL AS A MOBILE WEB APP (PWA)
1. Unzip this folder.
2. Upload all files (index.html, assets folder, icons, manifest and sw.js) together to any static HTTPS host such as GitHub Pages or Netlify.
3. On Android open the HTTPS address in Chrome, then use the menu > Add to Home screen / Install app.
4. The app works offline after initial visit. Local data is not synced across browsers or devices.

BEFORE REPLACING AN OLD DAYBLOOM
Export your JSON backup under Settings and import it into the new version as needed. On the same browser and origin, v1 local data is reused automatically.

FAN USE
Included Genshin Impact character art is from your supplied Drive folder, for personal use. Daybloom is an unofficial fan-inspired journal, not affiliated with HoYoverse. Please do not distribute copyrighted character art without rights.
